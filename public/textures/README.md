# Earth Atlas Textures

These equirectangular Earth textures (`earth-atlas.webp` and `earth-atlas.png`, 2048x1024) are procedurally rasterized locally at build time directly from the repository's public-domain Natural Earth 110m vector land geometry (`data/land.json`) and verified speaking city coordinates (`data/locations.json`).
Zero external runtime imagery APIs or proprietary third-party textures are used.
