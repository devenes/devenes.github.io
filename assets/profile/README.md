# Profile Headshots

This directory holds speaker profile photographs and headshots for Enes Turan.

## Recommended Specifications

- **File name**: `avatar.jpg` or `headshot.jpg`
- **Format**: JPEG or WebP
- **Dimensions**: 400x400 to 800x800 square or 4:5 portrait
- **Optimization**: Under 300 KB for fast initial page load

When placed here, you can reference it in the website header or about section.
